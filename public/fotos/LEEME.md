# Fotos tipo pasaporte

Pon aquí las fotos (formato vertical 7:9, por ejemplo 700×900 px, en .jpg o .webp)
y escribe su ruta en `src/data/site.ts`, en la lista `photos`. Ejemplo:

    { src: '/fotos/foto-01.webp', alt: { es: '…', en: '…' } },

Mientras `src` sea `null`, el sitio muestra un espacio reservado.
